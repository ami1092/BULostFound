# BULostFound Backend

Express + TypeScript API for matching lost and found items at Binghamton University.

## Tech stack

- Node.js, Express 5, PostgreSQL
- TypeScript (run in dev with ts-node + nodemon)

## Prerequisites

- Node.js 20+ and npm

## Setup

```bash
cd backend
npm install
cp .env.example .env   # then fill in values
```
